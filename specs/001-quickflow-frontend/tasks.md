# Tasks: QuickFlow (frontend layer)

**Input**: Design documents from `specs/001-quickflow-frontend/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/ui-contract.md, quickstart.md; backend
swagger `specs/001-quickflow-backend/contracts/openapi.yaml` (planning) and `loops/backend-dev/outputs/openapi.json`
(implementation, input of `generate_client`)

**Tests**: REQUESTED by the loop. Frontend unit tests are optional (Constitution III) and `layers.frontend.test` is
empty, so no spec files are written (assumption FA-1). The tests of every story phase are the testing loop's
Playwright MCP checks, written from the acceptance criteria against the selectors pinned **before any code** in
`contracts/ui-contract.md`. Each story phase therefore starts with a task that checks the story's contract
(generated operations + selector section) before the components are written.

**Organization**: grouped by user story; each phase is one loop milestone.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: US1..US6 from spec.md
- Paths: `frontend/src/app/...`. `frontend/` is scaffolded by the runner (Angular CLI 22.2.0, zoneless, routing, CSS,
  no SSR) before the first implement session; no task creates it. `frontend/src/app/api/` is generated by
  `generate_client` in every implement session and never edited by hand.
- Generated service, method, model and enum names are checked in `frontend/src/app/api/` before use (research R-2).
- Every element listed in `contracts/ui-contract.md` for the story carries exactly that `data-testid`.

## Dependencies & Execution Order

### Phase Dependencies
- **Setup (Phase 1)**: none
- **Foundational (Phase 2)**: Setup; needs `loops/backend-dev/outputs/openapi.json` (backend Foundational done) for `generate_client`
- **US1 (3), US2 (4), US3 (5), US6 (8)**: Foundational + the same backend story (`backend-dev:USn`)
- **US4 (6)**: Foundational, US1, US2, US3 + `backend-dev:US4`
- **US5 (7)**: Foundational, US1..US4 + `backend-dev:US5` (reuses `plan-card` from US4)
- **Polish (9)**: every story phase

### Within Each User Story
- The contract check task first; then [P] components; then the page that uses them.

### Parallel Opportunities
- Foundational T007–T012; US1 T016; US2 T022; US3 T027–T028; US4 T031–T033; Polish T044–T045.
