# Tasks: Task tags (frontend layer)

**Input**: Design documents from `specs/002-us-tags-frontend/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/ui-contract.md, quickstart.md; backend
swagger `specs/002-us-tags-backend/contracts/openapi.yaml` (planning) and `loops/backend-dev/outputs/openapi.json`
(implementation, input of `generate_client`)

**Tests**: REQUESTED by the loop. Frontend unit tests are optional (Constitution III) and `layers.frontend.test` is
empty, so no spec files are written (assumption FA-T8). The tests of the story phase are the testing loop's Playwright
MCP checks, written from AC-US1-1..6 against the selectors pinned **before any code** in `contracts/ui-contract.md`.
The story phase therefore starts with a task that regenerates the client and checks the story's contract (generated
operations + selector section) before the components are written.

**Organization**: one user story; each phase is one loop milestone. No Setup or Foundational phase: the frontend of
`specs/001-quickflow-frontend` (scaffold, proxy, API client wiring, `readProblem`, `NoticeService`,
`FieldErrorComponent`, Tasks page) is in place.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: US1 from spec.md
- Paths: `frontend/src/app/...`. `frontend/src/app/api/` is generated by `generate_client` and never edited by hand.
- Generated service, method and model names are checked in `frontend/src/app/api/` before use (research R-1).
- Every element listed in `contracts/ui-contract.md` carries exactly that `data-testid`.
- No client-side tag rules: no trimming, case change, length or count check in the UI (Constitution IV); the server's
  messages are shown.

## Phase 1: User Story 1 - Tag tasks and filter by tag (Priority: P1) 🎯 MVP

**Goal**: on `/tasks`, show each task's tags, add one or more tags to a task, remove a tag, and filter the list by tag

**Independent Test**: on `/tasks` alone, add "work, urgent" to a task, reload, filter by "work" / "WORK", remove
"work", try an empty tag, a 31-character tag and an 11th tag
