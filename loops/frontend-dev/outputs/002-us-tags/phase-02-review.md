## Risks
- **Swagger changed after client generation**: `loops/backend-dev/outputs/openapi.json` was rewritten by the backend
  polish phase (23:29) after the client was generated (23:14). Checked now: the changes are schema annotations only —
  `Task.tags` gained `maxItems: 10`, `uniqueItems`, item `minLength 1`/`maxLength 30` and a description; `TaskTags.tags`
  lost `maxItems: 2147483647`; `tag` query parameters gained descriptions. Operation ids, paths, parameter names/order
  and types are unchanged, so the regenerated `typescript-angular` client keeps the same signatures
  (`listTasks(q, status, priority, dueFrom, dueTo, archived, tag, sort, direction)`). `uniqueItems` could make the
  generator emit `Set<string>` for `Task.tags` instead of `Array<string>`; if it does, T007's build catches it and the
  UI code is adapted (iterate/convert), not the generated files.
- **Regressions**: any T006 fix touches code verified in phase-01; changes stay limited to real differences.
